Global Navigation Bar

A minimalist, airy navigation component designed for modern web applications. The navigation bar features a translucent black background with a subtle backdrop blur effect, creating a sophisticated glass-like appearance.

  • Full width with fixed height (64px)
  • Translucent black background (#000000) with 80% opacity
  • Backdrop blur effect (12px)
  • Border-bottom: 1px solid #333
  • Logo 'SYSTEM' on left using Inter Bold font
  • Centered navigation links in gray text
  • 'Feedback' button on right side
  • Hover states for interactive elements
  • Accessible with proper ARIA attributes
